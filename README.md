# Codex Harness Presentation (English)

A standalone HTML presentation: **Codex is a model inside a harness.**

It explains what a harness is, how the action loop works, which core components belong to it
(tools, context, sandbox & approvals, sessions, project memory) and how Codex and Claude Code
compare as model-plus-harness systems.

English edition of [codex-harness-praesentation](https://github.com/Arnie936/codex-harness-praesentation).

## Contents

A single file: [`index.html`](index.html). No build, no dependencies,
no external assets. All diagrams are inline SVG.

## View locally

Open the file in your browser, or:

```bash
python -m http.server 8000
# http://localhost:8000
```

## Deployment

Static hosting with zero configuration: Vercel, GitHub Pages, Netlify or similar.
On Vercel: import the repo, framework preset **Other**, no build command.
